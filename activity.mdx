---

The **Activity** page gives you a quick view of what has changed across your workspace. Use it to catch up on recent events without opening each page.

## Where to find it

In the admin app sidebar, select **Activity**. The page opens at `/activity`.

## Activity feed

The page lists recent events, one per row. Each row shows:

| Field | Description |
| --- | --- |
| **Title** | A short summary of the event, such as `Task completed`. |
| **Detail** | More context about the event, such as which employee or task it relates to. |
| **Status** | A label for the type of event, such as `New`, `Done`, `Export`, or `Updated`. |
| **Time** | When the event happened, shown as relative time, such as `12 min ago` or `Yesterday`. |

<Note>
  The feed currently shows a fixed set of sample events. It doesn't update when you add employees, complete tasks, or export reports.
</Note>
