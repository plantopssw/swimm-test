---

The **Task report** page gives you a snapshot of task progress across your whole organization. Use it when you need to compare workload between employees, see how much work is still open, or check how tasks are spread across priorities.

## Where to find it

On the [Employee tasks](/employee-tasks) page, select **View report**. The page opens at `/employees/tasks/report`.

To return to the task list, select **Back to tasks**.

## Summary cards

The top of the page shows three numbers for your organization:

| Card | Description |
| --- | --- |
| **Total tasks** | The number of tasks assigned across all employees. |
| **Open tasks** | The number of tasks that aren't complete. |
| **Completion rate** | The percentage of all tasks that are complete, rounded to the nearest whole number. |

## Employee workload

The **Employee workload** table compares assigned work and completion for each employee:

| Column | Description |
| --- | --- |
| **Employee** | The employee's name and role. |
| **Assigned** | The number of tasks assigned to the employee. |
| **Open** | The number of the employee's tasks that aren't complete. |
| **Progress** | The percentage of the employee's tasks that are complete. Employees with no tasks show `0%`. |

## Priority breakdown

The **Priority breakdown** card shows how many tasks have each priority: `High`, `Medium`, and `Low`. Each priority has a bar that shows its share of all tasks. The counts include both open and completed tasks.

<Note>
  The report doesn't include tasks you add or completion changes you make on the Employee tasks page.
</Note>
